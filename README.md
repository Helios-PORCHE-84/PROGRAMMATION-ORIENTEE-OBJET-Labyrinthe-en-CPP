# PROGRAMMATION-ORIENTEE-OBJET-Labyrinthe-en-C-.-
À partir d’une grille rectangulaire p × q on obtient un labyrinthe en ajoutant un certain nombre de murs pour séparer deux cases voisines. On convient en outre que ce labyrinthe est entouré de murs sur toute sa périphérie, de sorte qu’il n’est pas possible de sortir de la grille.
